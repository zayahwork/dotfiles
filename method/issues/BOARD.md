# BOARD

Generated from the issue files in this folder. Regenerate after any issue change. The
issue files are the truth; this is the view.

Empty. Nothing has been cut yet. A board appears when a PRD is run through
`/prd-to-issues`.

**A closed issue is renamed with a `✅-` prefix** so the file tree answers "what is done"
without opening anything, and the closed ones sort to the top. The prefix goes on when
the issue closes, never before. An issue an agent has finished but a person has not
judged does not get the prefix.
