# Progress

One tracker per thing we are building. Each one answers three questions in the same
order, so you can read any of them in twenty seconds:

1. **Where we are** - the state right now, in a line.
2. **What is next** - the single next action, and whose it is.
3. **Previous work** - what has already been done, newest first, with what proved it.

A tracker is not a plan and not a log. The plan lives in the PRD, the reasoning lives in
the grill record, the facts live in `library/`, and the history lives in git. This is the
one page that says where a thing stands when you come back to it after two days.

## Adding one

Copy the shape of an existing tracker. Three headings, newest first under Previous work,
and every claim carries what proved it. Add a row above. Update it in the same session
that changes the state, not later, because a tracker nobody trusts is worse than none.
